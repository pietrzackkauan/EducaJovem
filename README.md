# EducaJovem

## Descrição
Plataforma de Empregabilidade Jovem conectando jovens e empresas com oportunidades e aprendizado.

## Tecnologias Usadas
- React 18
- Tailwind CSS
- FontAwesome 6

## Funcionalidades
- Cadastro de usuários (alunos e empresas)
- Painel de controle para alunos e empresas
- Dashboard interativo
- Modo claro/escuro
