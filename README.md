# EducaJovem

Plataforma completa para alunos e empresas com cursos, progresso, certificados, quiz interativo e banco de talentos.

## Funcionalidades
- Portal do Aluno
  - Cursos com progresso
  - Certificados
  - Quiz interativo
- Portal da Empresa
  - Banco de talentos
  - Filtros de candidatos
  - Salvar candidatos
  - Enviar propostas de emprego

## Tecnologias Usadas
- React 18
- Tailwind CSS
- FontAwesome
- Canvas Confetti

## Como Usar
1. Clone o repositório.
2. Abra o index.html em um navegador.
3. Aproveite a plataforma!
