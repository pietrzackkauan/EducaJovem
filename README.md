# EducaJovem
Plataforma de Empregabilidade Jovem.

## Tecnologias Usadas
- React 18
- Tailwind CSS
- FontAwesome 6
- LocalStorage (para persistência de dados)

## Funcionalidades
- Cadastro e Login de usuários (Alunos e Empresas).
- Dashboard personalizado para Alunos e Empresas.
- Sistema de cursos com progresso.
- Busca de talentos e ofertas.
- Salvar candidatos e histórico de contratações.
