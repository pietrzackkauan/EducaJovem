# EducaJovem

## Descrição
Plataforma de Empregabilidade Jovem.

## Tecnologias Usadas
- React
- Tailwind CSS
- FontAwesome

## Funcionalidades
- Cadastro e login para alunos e empresas.
- Visualização e gerenciamento de cursos.
- Recomendação de talentos para empresas.
- Modo claro e escuro.
